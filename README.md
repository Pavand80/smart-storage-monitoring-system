# Smart Storage Monitoring System

## Overview
A Real-time IoT-based Smart Storage Monitoring and Inventory Management System built using React, Node.js, ESP32, MQTT, and PostgreSQL.

## Features
- Real-time sensor monitoring
- Temperature and humidity monitoring
- Motion detection
- Smoke and fire detection
- QR-based inventory management
- Add and delete inventory items
- Live dashboard updates
- PostgreSQL database integration

## Tech Stack

### Frontend
- React.js
- Vite
- Material UI

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

### Hardware
- ESP32
- DHT11 Sensor
- MQ-2 Smoke Sensor
- PIR Motion Sensor

### Communication
- MQTT (HiveMQ)
- Socket.IO

## Getting Started

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
